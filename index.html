Write an Email

7 Min.0–5 Punkte120–150 Wörter
1 Min.Lesen, 3 Bullets + Ton notieren
5 Min.Schreiben
1 Min.Korrektur
RegelJeder Bullet: Aussage + Detail
Dear Professor Lee, / Dear Ms. Carter, / Hi Sam,

[Opener]   I hope you're doing well. I'm writing about ...
[Bullet 1] So far, I've really enjoyed ..., especially ...
[Bullet 2] Unfortunately, I've just found out that ...
           As a result, I wouldn't be able to ...
[Bullet 3] Would it be possible to ...?
           Alternatively, I could ...
[Closing]  Thank you for your time and understanding.
           I look forward to hearing from you.

Best regards,
Tom

Korrektur-Checkliste (letzte Minute)

  1. Anrede und Name wie im Prompt?
  2. „I“ überall groß?
  3. so far / since / just → Present Perfect?
  4. Lehnübersetzung aus dem Deutschen? (submit, same-minded, eventually)
  5. Alle 3 Bullets beantwortet, Bullet 3 mit 2 Vorschlägen?

Email-Schemas nach Szenario

  • Bitte / Erlaubnis: Anlass → Grund + Detail → konkrete Bitte (I was wondering if …) → Alternative → Dank
  • Beschwerde / Problem: positiver Einstieg → Problem sachlich + Detail (It seems that …) → Folge → Lösungsvorschlag → Bitte um Rückmeldung
  • Absage / Entschuldigung: klare Absage (I'm afraid I won't be able to …) → Grund → Entschuldigung → Ersatz anbieten
  • Vorschlag / Einladung: Anlass → Idee (I'd like to suggest …) → Nutzen → Details (wann, wo) → Let me know if you're interested.
  • Feedback / Dank: Dank + was konkret gut war → warum es geholfen hat → ein Verbesserungsvorschlag → Abschluss
  • Information anfragen: wer du bist + Anlass → was du schon weißt → 2 konkrete Fragen → Dank

Academic Discussion

10 Min.0–5 Punkte120–160 Wörter (mind. 100)
1,5 Min.Professor + 2 Posts lesen
1 Min.Position + Beispiel festlegen
6 Min.Schreiben
1,5 Min.Korrektur
[1 Bezug + Position]
While Paul makes a fair point that ..., I believe that ...

[2 Hauptgrund]
The main reason is that ..., which means that ...

[3 Neuer Aspekt – entscheidend für 5/5]
Another factor that hasn't been mentioned is ...

[4 Konkretes Beispiel]
For instance, when I was studying industrial engineering, I ...
As a result, ...

[5 Abschluss]
For these reasons, I'm convinced that ...
  • Welche Seite du wählst, ist egal. Nur die Studierenden wiederholen deckelt die Note.
  • Mindestens 2 komplexe Sätze: Relativsatz, Konditional, Konzession (Admittedly …; however …).
  • Einfache Zeitformen halten die Fehlerquote niedrig.

Varianten je Haltung

  • Einem Studierenden zustimmen: Zustimmung mit Namen → Grund vertiefen oder neuen ergänzen → Beispiel → Gegenargument des anderen entkräften → Abschluss
  • Beiden widersprechen: beide kurz anerkennen → eigene dritte Position → Grund → Beispiel → Abschluss

Take an Interview

4 Fragen45 Sek. je Fragekeine Vorbereitungszeit90–110 Wörter
Commit0–5 s · direkte Antwort
Detail5–20 s · Hauptgrund
Elaborate20–38 s · konkretes Beispiel
Finish38–45 s · Abschluss
Commit     Honestly, I'd say ... / If I had to answer right now, I'd say ...
Detail     The biggest reason is that ...
Elaborate  For example, last year when I ... In the end, ...
           That showed me that ...
Finish     So overall, that's why ... / So that's my take.

Varianten je Fragetyp

  • Erfahrung (Fragen 1–2): Situation → was ich gemacht habe → Ergebnis → was ich gelernt habe
  • Präferenz („X or Y?“): Wahl → Vorteil von X → kurzer Nachteil von Y → Beispiel → Abschluss
  • Meinung (Fragen 3–4): Position → Grund → Some people argue …, but … → Beispiel → Abschluss
  • Zukunft / Hypothese: Plan → Grund → wie konkret → erwartetes Ergebnis

Deine Beispiel-Geschichten (vorbereiten, flexibel einsetzen)

  • Atlantiküberquerung: Teamwork, Herausforderung, Risiko, Planung
  • Capgemini: Arbeit im Team, Technologie und KI, Deadlines, Präsentieren
  • Bachelorarbeit: Zeitmanagement, Selbstdisziplin, Forschung
  • Vorstand im Wassersportverein: Verantwortung, Organisieren, Ehrenamt

Listen and Repeat

7 Sätze8–12 Sek.wird länger
  1. Auf das Gerüst hören: Subjekt – Verb – Objekt.
  2. Den Satz in 2–3 Sinnblöcke zerlegen.
  3. Sofort nach dem Ton beginnen, Intonation kopieren.
  4. Kein Wort ersetzen. Endungen (-s, -ed) und Artikel deutlich sprechen.
  5. Training: täglich 10 Min. Shadowing über Lautsprecher, ohne Kopfhörer.

Build a Sentence

10 Itemsca. 35 Sek. je Itemalles oder nichts
  1. Kontextsatz → Zeitform und Satztyp (Frage oder Aussage)
  2. Subjekt + finites Verb zuerst setzen
  3. Blöcke einordnen: Präpositionalphrase, Relativsatz, Adverb
  4. Indirekte Frage ohne Inversion: … where the library is
  5. Einmal komplett im Kopf lesen

Reading und Listening

  • Adaptiv: Das erste Modul fast fehlerfrei lösen, sonst kommt das leichtere zweite Modul mit niedrigerer Obergrenze.
  • Complete the Words: Unterstriche zählen → Wortart aus dem Satz → Suffix-Familie (-tion, -ment, -al, -ly) → nie leer lassen → Rechtschreibung prüfen.
  • Listen and Choose a Response: Die richtige Antwort ist oft indirekt oder idiomatisch.
  • Notizen: nur Thema → Beispiel → Haltung des Sprechers.
